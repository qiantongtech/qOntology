# qOntology V1.0.0 更新升级文档

## 一、数据库脚本执行

升级前请先执行数据库初始化/升级脚本。

### 1. 进入初始化目录

进入项目 `initialization` 目录。

### 2. 执行数据库脚本

任选其一执行以下初始化脚本：
* `v1.0.0初始化.sql`
* `latest初始化.sql`

---

## 二、项目环境

### 1. 环境要求

| 环境    | 要求              |
|-------|-----------------|
| JDK   | **JDK 17**      |
| Maven | **3.9.9 及以上版本** |

---

## 三、升级注意事项

1. 请使用 **JDK 17** 启动项目，避免因 JDK 版本不兼容导致项目启动失败。
2. **升级前请备份数据库**，避免升级过程中出现异常导致数据无法恢复。
3. 执行数据库脚本前，请确认当前数据库版本及执行环境，避免重复执行升级脚本。
4. 项目升级完成后，请检查服务是否正常启动，并确认核心功能可以正常访问。
